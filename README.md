# FoxLove — Android

Нативное Android-приложение на Kotlin + Jetpack Compose.

## Сборка APK через GitHub

1. Создай пустой репозиторий на GitHub.
2. Загрузи в него все файлы этого проекта.
3. Открой вкладку **Actions**.
4. Выбери **Build Android APK** и нажми **Run workflow** (или просто отправь push в `main`).
5. Открой завершённый запуск workflow.
6. В разделе **Artifacts** скачай `FoxLove-debug-apk`.
7. Распакуй архив и установи `app-debug.apk` на Android.

Root не требуется. Для установки APK может понадобиться разрешить установку приложений из выбранного источника.

## Управление

Коснись экрана, чтобы начать историю заново.

## Сценарий

Лиса пробегает по заснеженной поляне, находит светящийся камешек-сердечко, наклоняется к нему, нюхает, затем поднимается на задние лапки. Появляется надпись «Я тебя люблю».
